# Changelog

## 0.2.0 (2026-09-03)

- Reworked the list page around a single overview band, compact command area, and stronger table hierarchy.
- Rebuilt the record page as a continuous three-column workspace with quieter rails and a more focused timeline.
- Added semantic status and priority tokens without changing ticket data or controls.
- Tightened navigation, typography, spacing, borders, hover states, and focus treatment across both themes.
- Updated the settings panel language and visual system to match the ticket workspace.
- Replaced heavy card shadows and fade effects with restrained tonal layering.

## 0.1.0 (2026-09-03)

- Added a compact ticket list theme with clearer table hierarchy and status accents.
- Added a coordinated three-column ticket record theme.
- Added Midnight, Porcelain, and automatic color modes.
- Added density, analytics shelf, and navigation width controls.
- Matched HubSpot's current toolbar, navigation, cards, timeline fades, and loading states in both color modes.
- Added accessible focus treatment and verified AA contrast for primary and muted text.
- Added sanitized fixture tests and offscreen visual capture tooling.
